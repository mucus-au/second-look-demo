# Second Look public demo

Static publication of the prepared Tallowwood preview from product-lab c3edd50.
Only index.html, app.js and style.css are public assets. No model execution,
server-side data storage, analytics or uploads. Inputs remain in browser storage.
Every page load opens the problem input screen. New visitors see Tallowwood prefilled;
returning visitors retain their local draft. Reset walkthrough restores the example.

Source changes must preserve the offline evidence in the product-lab repository.

Hosted with GitHub Pages from /docs on main. Sites registration was unavailable.
